# Control Center

Личный локальный интерфейс: быстро понять состояние проектов и выбрать следующий шаг. UI и документация владельца на русском.

## Архитектурный контракт

Архетип: пользовательское приложение с локальными возможностями и одним Node.js API. Сценарии: сканирование → сводка → изменение фокуса → задача/идея/решение → связь.

- `src/App.vue`, `src/main.ts` — композиция и навигация; `src/features/` — экраны; `src/shared/` — API-клиент, подписи, общие компоненты.
- `server/index.ts` — запуск, `server/app.ts` — HTTP-композиция. `server/projects/` — обнаружение, метаданные, сводка; `server/git/`, `server/filesystem/` — внешний доступ; `server/db.ts` — SQLite; `server/records.ts` — задачи, идеи, решения.
- `shared/` — схемы и модели без Node.js, Vue и хранилища. Frontend и backend импортируют shared. Frontend не импортирует backend/Node.js. Backend не импортирует frontend. Общий frontend-код не импортирует экраны.
- Прямые вызовы SQLite и адаптеров из владельцев сценариев допустимы. Нет repository/use-case на каждый CRUD, DI-контейнера и AI-слоя. Пересмотр при втором клиенте или самостоятельном сложном сценарии.
- Guard: `scripts/check-boundaries.ts`; положительный и отрицательный примеры: `tests/boundaries.test.ts`.

## Инварианты

SQLite хранит пользовательские данные и последний снимок обнаружения. YAML — необязательная исходная сводка. Сохранённые в SQLite метаданные приоритетны. Экспорт YAML явный, проверяет версию и сохраняет неизвестные поля. Сканер не запускает код проектов и не обходит symlink. API только loopback, проверяет Host/Origin, не допускает произвольной записи файлов.

## Документация

`README.md` — переносимое руководство пользователя. `.local/PROJECT_MAP.md` — карта для владельца; `.local/DECISIONS.md` — решения и условия пересмотра; `.local/PLAN.md` — рабочий план. Локальные документы не публикуются. Обновлять вместе с контрактами.

## Проверки и поставка

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`. Проверить пустую базу, настройку каталогов, отсутствие YAML, dirty Git и основной сценарий. Commit/push/публикация требуют разрешения. Формат коммитов не установлен; hooks и CI не подключены.

## Не сейчас
