# Карта решений

Первоначальные решения локального приложения. Здесь сохранены основания, дополняющие [текущую карту](../DECISIONS.md); результаты отдельных запусков не являются частью решения.

## Границы кода — принято

Контракт: `.ai-rules/PROJECT_RULES.md`. Один процесс Express, Vite middleware в разработке и статическая сборка в production. Один origin и одна команда запуска. Отдельные сервисы добавили бы запуск и CORS без пользы для одного пользователя. Пересмотреть при реальном удалённом клиенте.

## SQLite и YAML — принято

SQLite хранит ручные данные и кэш обнаружения, YAML служит исходным значением. После сохранения полной сводки в UI действует SQLite; возврат к YAML отдельным действием. Экспорт явный, с проверкой хэша файла, без перезаписи неизвестных полей. Цена: два представления, поэтому UI сообщает источник. Автоматическая двусторонняя синхронизация отвергнута из-за скрытых конфликтов. Пересмотр при нескольких редакторах метаданных.

## SQLite runtime — принято

Встроенный `node:sqlite` не требует сборки native addon на Windows. Минимум Node 22.17; на этой версии API экспериментальный и выдаёт предупреждение. Синхронные короткие SQL-запросы приемлемы; Git и filesystem асинхронны. Пересмотреть при большой базе или изменении runtime API.

## Обнаружение — принято

Признаки: `.git` (включая worktree), `PROJECT.yaml`, `package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, `AGENTS.md`. Обход не спускается внутрь проекта и symlink. Вложенные проекты можно добавить отдельным корнем. Отсутствие commit — неизвестная активность. Ошибки показываются, ручные данные не удаляются.

## Локальная граница — принято

Loopback, строгие Host/Origin, JSON и custom header для записи защищают от внешних страниц. Экспорт только в известный проект внутри настроенных корней, без symlink. Git вызывается через execFile без shell, fetch/push и project scripts. Пересмотреть до удалённого доступа.

## Архитектурная проверка — принято

Небольшой анализ импортов TypeScript/Vue защищает границу backend/browser на настоящем дереве и отрицательной фикстуре. Цена: поддержка устойчивых правил. Заменить при появлении эквивалентного lint-правила; это не доказательство всей архитектуры.
